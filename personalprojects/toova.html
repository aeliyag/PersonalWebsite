Toova

Role: Co-founder, full-stack engineer

toova.net — a 3D dorm-room visualizer that turns 2D photos into interactive 3D spaces so students can plan furniture and layouts before they buy.

What I built

  • 2D→3D pipeline using TripleSR and Pixel3D, integrated end-to-end into the product.
  • GPU inference on AWS EC2 with Docker, plus Lambda-based server orchestration.
  • SQL backend for rooms, furniture, and spatial layouts so users can save and revisit setups.

Product

  • 30+ customer-discovery interviews; started with textbook price comparison, then pivoted to dorm visualization based on what students actually needed.
  • Recruited five design partners and turned their feedback into feature priorities.
  • Summer 2026: more visualizer features and the first 40 users (at least one room created).
